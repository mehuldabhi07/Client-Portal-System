## 📌 Project Overview
The **Client Portal System** is a responsive web application designed for client self-service and management. Built as a pure client-side frontend solution (no backend database required), it provides modules for dashboard tracking, profile management, document management, ticket submission, invoice tracking, and live messaging.

---

## 🚀 Features
- **Dashboard:** At-a-glance status counts and recent system activity log.
- **Profile Management:** View and update client contact details with instant state updates.
- **Project Tracking:** Monitor active projects, status, and completion progress.
- **Document Center:** Add and view project documents with simulated downloads.
- **Support Desk:** Submit support tickets with custom priorities.
- **Invoices & Billing:** Inspect billing history and open invoices.
- **Messaging:** Interactive messaging simulating communications between Client & Admin.
- **Admin & Client View Switcher:** Instant role-switching to simulate different perspectives.
- **Theme & Responsiveness:** Dark Mode toggle and full support for mobile, tablet, and desktop views.

---

## 🛠️ Technologies Used
- **HTML5:** Semantic structure and layouts.
- **CSS3:** Custom styles, CSS variables, Flexbox, CSS Grid, and media queries.
- **JavaScript (ES6):** State handling, DOM updates, event handling, and local storage persistence.
- **Font Awesome:** Icons for UI components.
